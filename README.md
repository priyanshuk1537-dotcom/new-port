# Priyanshu Kumar — Portfolio

A modern monochrome portfolio for a B.Tech Computer Science student specializing in AI/ML and Full Stack Web Development.

## Run locally

No build tools are required.

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. The hero image is stored as `hero.png`.

## Customize

- Update text/content in `index.html`.
- Update colors/layout in `style.css`.
- Update interactions in `script.js`.
- Replace `hero.png` with a different hero image if needed.
